\section*{Data and Code Availability Statement}
All source code, the \texttt{SOC-ITPI-24} benchmark, multi-corpus evaluation scripts, empirical log-likelihood lookup tables, and trace-driven decision-theoretic sensitivity pipelines supporting the findings of this study are openly available in an anonymous repository for double-blind peer review at \url{https://anonymous.4open.science/r/epistemic-fluency-trap/} (camera-ready archival repository: \url{https://github.com/tranducle/epistemic-fluency-trap}). The underlying telemetry records are derived from four public cybersecurity repositories (\texttt{OTRF Security-Datasets}, \texttt{SALAD-SOC}, \texttt{LMD-2023}, and \texttt{CISA KEV}), with all prompt-injection strings sanitized using non-weaponizable administrative text.

\section*{Ethics Statement}
This study did not involve any human participants, human-subject experiments, surveys, interviews, or animal subjects. All empirical evaluations and trace-driven decision-theoretic analyses were conducted exclusively on publicly available, de-identified cybersecurity telemetry datasets (\texttt{OTRF Security-Datasets}, \texttt{SALAD-SOC}, \texttt{LMD-2023}, and \texttt{CISA KEV}). Accordingly, institutional review board (IRB) human-subjects approval and informed consent were not applicable.
